## 口径与用法

- 当前发布源含 178 条来源记录、129 条政策目录记录；本次另合并 12 份研究来源台账及其中明确列出的附件链接，共 547 条出处记录、按原始 URL 精确去重后 257 个链接。
- 这不是全部已下载文件的清单，也不表示链接全部有效、资料全部核验或学校范围全部覆盖。相同 URL 的多个来源记录保留在 JSON 中，不凭标题合并。
- 发布源的 `official_source_pending_review` 与研究源的 `snapshotted` / `parsed_pending_review` 等为原始状态，均不升级为 `verified`。
- 标题、年度、区和日期沿用采集台账；个别原始分类可能粗糙。尤其“五年级到六年级”不能因原台账标为 primary 就推荐给幼升小用户。
- 2025 学年统计与 2026 招生政策分开使用；采集日期、网页发布日期、正文印发日期和招生年度不是同一个字段。
- 链接抽查：2026-10-23 成功读取市级义务教育实施意见、学前教育入园通知和学前教育机构目录入口；其他链接未逐一重新联网检查。HTTP 历史链接按原样保留，不擅自改写为 HTTPS。
- 下文按地区列出唯一链接；实际来源标题与状态以 JSON 中对应记录为准。链接收录不代表正文核验。
